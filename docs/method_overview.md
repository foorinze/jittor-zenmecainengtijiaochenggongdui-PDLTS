# 方法概览

任务是将带噪三维点云转换为相同点数的去噪点云。PD-LTS Light 利用局部图特征扩展坐标表示，通过可逆流映射到潜空间，切除预设噪声通道后反向重建；公开 Jittor 实现使用仿射耦合层。

```text
带噪点云 → 整云归一化 → 局部块与图特征
         → 可逆流 → 潜空间噪声通道切除 → 逆变换
         → 局部块候选拼接 → 第一遍输出
         → 针对第一遍实际输出训练的第二遍模型 → 去噪点云
```

局部块拼接保持最终输出点数；推理只使用带噪输入和模型权重。A 榜另有评分归一化损失微调与冻结方向场后处理，B 榜采用普通双向 Chamfer（倒角距离）训练的两遍专训链。

仿射耦合层直接求逆，采用常规自动求导，减少了求根和隐式梯度模块的移植与维护工作。这是实现取舍，不构成普遍加速或与原版统计等价的证明。名义 Jittor 单调/仿射对照存在结构身份疑点，详见 [结构实验](../experiments/architecture.md)。
