# 结构与表示

## 4. 结构与表示实验

### 4.1 Affine Coupling 与 iMonotone

原始 iMonotoneBlock 的正逆向依赖迭代求根、收缩约束和隐式/近似反向传播。Jittor 主线改用 AffineCoupling（仿射耦合层），通过闭式公式直接求逆，并使用常规自动求导。

PyTorch 结构对照中 iMonotone 与仿射耦合为 82.33/80.03；该实验还改变了结构和部分配方，不能当作单一结构因果结论。Jittor 20/100 轮历史结构标签与训练参数清单存在冲突，分数不能作为两种结构相当的证据。见 [结构身份核查](../experiments/evidence/structure_identity_review.json)。

**采用判断**：保留仿射耦合，主要依据是实现可运行、可求逆、可反向传播且维护成本较低；没有宣称普遍训练加速或原版等价。

### 4.2 宽度、层数和归一化

增加流层数或耦合层宽度的实验出现负向结果；GroupNorm（分组归一化）小规模筛查有正信号，但扩大到形状不重叠的完整训练后没有达到预设门槛。曾有包装器没有转发归一化参数，名义消融实际没有改变模型。

**经验**：结构消融前先检查模型实例、状态键和实际配置；小规模正向只代表筛查结果，必须用同条件、形状隔离的完整评测复核。不要把不同宽度模型之间的分数差写成归一化的纯因果收益。
