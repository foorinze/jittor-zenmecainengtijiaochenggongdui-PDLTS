# 数据与评测

## 1. 数据、预处理和评测

### 1.1 数据处理必须先于模型选择

- **问题**：带噪点云、干净点云、网格和局部块是否处在同一坐标和点数契约下。
- **改动**：检查采样、配对、噪声构造、归一化文件、局部块切分、缓存清单和输出点数；A/B 训练链分别保留数据清单和来源。
- **结果**：评测器对缺失文件、点数错误、非有限预测和预测缺失有检查；合成用例验证了非平凡平移和缩放，但没有穷尽归一化参数异常，不能视作 NaN/Inf 分母防护已完整验证；合成黄金样例与两种 P2S 后端验证通过。
- **采用判断**：数据处理与评测契约进入公开复现链。
- **可复用经验**：先固定坐标变换和样本完整性，再比较模型；“能生成数组”不等于“评测输入有效”。
- **证据**：[评测与归一化](../docs/evaluation_protocol.md)、[发布验证](../docs/release_preparation.md)、[A/B 复现指南](../b_board/reproduction.md)。

比赛数据集、预测数组和大型缓存不随仓库发布；公开的是数据准备方法、格式、脚本和评测实现。原始 B 榜训练对曾使用未固定的 Python `hash()`，所以当前脚本能复现流程，但不承诺逐位重建历史权重。

### 1.2 MOCK 不是线上成绩的替代品

- **问题**：本地样本是否能支持快速筛选，又是否会被误解为官方成绩。
- **改动**：使用 mock20、mock200 和 B 榜 mock_b 做本地筛选，保存 CD、P2S、Final、有效样本数和逐形状结果；线上成绩单独记录。
- **结果**：本地分数能用于路线筛查，但与线上存在偏移，且不同规模不能横向拼接。
- **采用判断**：MOCK 用于决策和回归检查，online 只用于最终提交结果。
- **可复用经验**：每个数字必须同时说明数据集、基线、是否读取真值、评测后端和样本数。
- **证据**：[实验总览](../experiments/overview.md)、[评测与归一化](../docs/evaluation_protocol.md)、[方法比较证据](../experiments/evidence/method_comparison_evidence.json)。
