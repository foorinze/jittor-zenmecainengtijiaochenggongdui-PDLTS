## 10. 给后来者的检查顺序

1. 先验证数据身份、坐标系、归一化和评测分数分母。
2. 再确认模型配置真正生效，并保存状态键和命令。
3. 先做完整点云基线，再看局部损失和机制指标。
4. 修改单个因素时固定数据、初始化、预算和评测范围；混杂因素必须明确标注。
5. 对后处理同时检查生成质量、覆盖、两个 CD 方向、P2S 和 Final。
6. 选择候选时不要只看 AUC 或逐点损失，必须执行固定点数的整集合解码。
7. 把“未跑完”“跑通但未提分”“负向”和“证据不足”分开归档。

本文公开的是已整理的实验经验和证据入口，不是全部历史日志的一键复现包。比赛数据、完整预测数组、大型缓存和未全部公开的历史诊断程序仍不随仓库提供。
