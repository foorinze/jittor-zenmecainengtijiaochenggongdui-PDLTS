# Oracle 实验与可部署方案的差距

后期实验反复出现同一结果：读取干净点云或真实曲面的 oracle（使用特权信息的理想参照）可以明显提高分数，但把这些信息换成带噪输入、模型预测和学习得到的估计后，收益大幅缩小，部分方案反而降低分数。

这些实验说明现有输出仍有改进空间，也说明“存在更好的点集”与“能从推理输入中找到这个点集”是两个不同的问题。我们尝试了匹配目标蒸馏、位移场学习、曲面误差估计、密度校准、候选点选择和扩散桥。最终采用的基础模型与第二遍专训取得了实际收益，但没有达到这些 oracle 的结果。

本文按问题和实验对照组织。A 榜主要数字见 [指标摘录](evidence/oracle_evidence.json)，每组保留原始字段及来源文件的 SHA-256（哈希校验值）；早期实验详表见 [A 榜实验记录](a_board_atlas.md)。第 2.6 节补充 B 榜后期开发实验，依据为 [研究指标摘录](evidence/research_evidence.json)。两榜诊断均不计作线上成绩。

## 1. Oracle 的收益有多大

记带噪输入为 `X`，基础预测为 `Q`，干净目标点集为 `Y`，真实曲面为 `S`。部署时可以读取 `X`、`Q` 和固定模型参数；下表的 oracle 额外读取 `Y` 或 `S`。训练阶段使用训练集真值作监督，与推理阶段读取待评测样本的真值，是不同的条件。

| 实验 | Oracle 使用的信息与操作 | 评测范围 | 基线与 oracle 结果 | 证据 ID |
|---|---|---|---|---|
| 局部一对一匹配 | 读取 `Y`，在局部稀疏匹配图上把 `Q` 移向对应干净点，未匹配点保留 | 同次 mock200（200 样本本地模拟评测） | Final **83.72 → 99.51**；oracle CD **99.30**、P2S **99.72**；200/200 有效 | `assignment_base`、`assignment_oracle` |
| 完整点云梯度更新 | 读取 `Y`、`S`，沿 CD（倒角距离）与 P2S（点到表面距离）目标的下降方向更新 16 步 | 100 个开发样本按形状划分为 80 个训练、20 个验证 | 相对同批基线 **+7.0330 Final** | `flow` |
| 真实曲面法向修正 | 读取 `S`，依据真实法向与离面误差修正已有 `Q` | 开发训练池中的 20 个形状 | **+3.8592 Final**；CD **+3.9548**、P2S **+3.7635**；20/20 正向 | `surface_oracle` |
| 固定候选池选择 | 候选由 `Q/X` 构造；读取 `Y` 决定从 100,000 个候选中保留哪 50,000 个 | 另一个固定开发验证集，20 个形状 | Final **84.4060 → 90.1869**，提高 **5.7809**；20/20 正向 | `candidate_selection` |

第一组尤其接近满分，但它直接贴合干净点，P2S 也随之受益。历史记录已将这种 P2S 结果标为真值贴合效应，不能用它预测真实网络的 P2S 表现。它支持“固定输出点数下存在高分构造”，没有证明实际模型能恢复相同匹配。

这里的 oracle 是已测构造，不是经过证明的全局最优上界。四组使用不同基线和样本，增量不能相加，也不能与最终线上 84.10 相减得到“还差多少分”。后期的 20 个开发验证形状与历史 mock20 不是同一个集合，部分验证集合还用于多条路线的比较，结果应视为开发证据。表中前两组还分别使用单遍模型与后期专训输出，并非都在改进单遍模型。

## 2. 尝试过哪些方法

### 2.1 学习匹配目标和位移场

最直接的做法是把 oracle 的目标点或位移当作监督，训练一个推理时只读取 `X/Q` 的模型。

| 方法 | 实验结果 | 能支持的判断 |
|---|---|---|
| 固定一对一匹配残差蒸馏 | 100 样本、3 轮训练后 mock20 为 82.99，原预测为 83.01；单样本拟合的位移方向与幅度恢复也弱 | 这次失败不只是验证集泛化问题；模型在拟合目标本身时已有困难 |
| 最近邻目标与局部近一对一目标续训 | 两种目标训练 50 轮后分别为 **81.30、81.29**，均低于原预测 **83.01**；训练损失仍下降 | 提高匹配的一对一程度没有改善这组训练结果；固定目标的局部块监督未转化为完整点云收益 |
| Sinkhorn（软最优传输）、邻域消息传递与拓扑约束 | 软匹配损失可下降，部分运行梯度有效，但完整点云回放出现重复点增加、位移失控或局部拓扑破坏 | 优化器能降低代理损失，不足以说明点集质量改善 |
| 平滑径向基场、多尺度控制点与 Transformer（注意力网络） | 平滑约束可保护局部结构，却同时压小有效位移；注意力网络改善低频控制量，高频层方向余弦仍约 0.44 | 输出表示存在取舍：更平滑的场更稳定，但未必能表达 oracle 依赖的细粒度重排 |
| 完整点云梯度控制器 | 33 维局部统计、6 个固定向量基和多层感知器，训练 30 轮；同批 oracle 为 **+7.0330**，模型更新 16 步为 **-0.9437**，0/20 正向，95% 置信区间 **[-1.3609, -0.5904]** | 学到的方向不足以支持连续多步更新；不能仅因向量基能够张成三维空间，就认定条件映射足够 |

前四项对应实验记录 `A-ASSIGN-02` 至 `A-ASSIGN-09`；两种目标续训的原始分数见 `distill_nn`、`distill_local`，完整点云控制器见 `flow`。

完整点云控制器的前两步曾有约 +0.014、+0.016 的微小正收益，随后转负。每步把低相关方向归一化到固定幅度，会持续放大方向误差。这支持迭代误差累积的解释。

我们也补做了训练时长对照。同一模型与数据从头训练 120 轮，末轮训练方向余弦为 **0.0388**；另一组加载原 30 轮模型权重、重建优化器并追加 90 轮，余弦升到 **0.1293**，仍低于预设 **0.15**。两组都未进入完整验证集的多步评测，不能把拟合指标换算成分数，见 `flow_longer_fresh`、`flow_longer_warm`。追加训练确有改善，但原优化器状态未保留，后者不是严格续训；结果削弱了“只差训练轮次”的解释，没有证明优化已穷尽或所有位移场都不可学。

### 2.2 给模型补上自己实际访问的状态

为检查失败是否主要来自训练时只见过教师轨迹，我们做了 DAgger（聚合模型自身轨迹上的监督数据）式实验：收集学生实际走到的 320 个状态，重新计算教师动作，再与原教师状态一起训练。

这组实验使用 64 个训练形状、16 个验证形状，起点是真实曲面上的投影，仍属于带特权条件的机制实验。加入新状态后，连续更新增量相对单步增量累计值的比例由 **2.68% 变为 2.51%**，相对特权起点的 Final 增量仅 **+0.0413**。训练与验证的汇总方向余弦分别为 **0.4745、0.4785**，两者接近。证据见 `state_aggregation`。

补充轨迹监督没有恢复连续更新的收益，说明“只要见过自身轨迹就能修复”不符合这次结果。固定容量下的拟合精度、离面误差累积及目标归一化仍是候选原因。一轮数据聚合、固定模型和 8 轮训练不足以证明轨迹分布偏移完全无关。

### 2.3 先恢复曲面，再修正点的位置

真实曲面修正得到 **+3.8592**，说明离面误差值得处理。我们进一步测试了局部平面、邻域平滑、全局形状先验和较大尺度的曲面拟合。

| 对照 | 结果 | 证据 ID |
|---|---|---|
| 真法向 + 邻域真实离面误差，邻域大小 8 | **+1.0177 Final**，20/20 正向 | `normal_shrink` |
| PCA（主成分分析）法向，邻域大小 8 | **-0.8677 Final** | `normal_shrink` |
| 同尺度直接平滑点的位置 | **-1.8624 Final** | `normal_shrink` |
| 学习全局曲面误差先验，70/30 形状划分、24 轮 | 训练相关性 **0.1378**，验证均方根相关性 **0.1295**；验证 **-0.0414 Final** | `surface_learned` |
| 局部移动最小二乘等经典曲面估计，选参后验证 | 30 个验证形状上最好方案 **-0.0298 Final**；22/30 正向，但均值仍负 | `surface_classical` |

真实法向修正使归一化离面残差从约 **0.4895 降至 0.0841**。估计曲面自身存在误差时，移动量即使足够，也未必沿正确方向；把残留的几何细节一起压平，还会损害反向 CD 所衡量的覆盖。这里的尺度单位是该实验的局部间距 `h0`，不与其他噪声审计的间距单位直接混用。

学习式估计在训练集上的相关性也低，因此“只是在新形状上泛化不好”不足以解释它。但训练与验证接近，只能定位到当前特征、模型、目标和优化条件下的拟合不足，不能单独证明输入本身没有足够信息。

### 2.4 从已有候选中选择点

固定候选池实验把问题从“生成新坐标”缩小到“选对已有坐标”。同一池中，真值选择得到 **+5.7809**；因此这组实验的首要问题已不是候选池完全没有合适的点。

| 选择方法 | 同一开发验证集上的结果 |
|---|---|
| `Q/X` 跨点云一致性评分与体素分配 | **-3.2439 Final** |
| 把真值最近邻投票的参照集由 `Y` 换成 `X` | **-3.1243 Final**，0/20 正向 |
| 同一投票，改用支持度补齐不足的候选 | **-3.2116 Final**，0/20 正向 |
| 每对基础点与中点候选二选一，梯度提升树学习选择 | 两个阈值分别约 **-0.00054、+0.00002 Final** |
| 同样二选一约束，但由真值选择 | **+1.8483 Final** |

证据见 `candidate_selection`、`input_vote`、`pair_selection`。中点候选由基础点与邻近带噪点构造，本身就向 `X` 偏移。用 `X` 再投票时，约 76% 的入选点是这类中点；真值选择只有约 44%。投票结果与真值选择的重合率 **46.7%**，还低于保留基础点的 **56.0%**。这与候选构造引入的偏置一致，不能只解释为投票噪声太大。

二选一还有独立的结构限制：自由 oracle 经常同时选中同一对的两个候选，或两个都不选，二者比例各约 32.4%。强制每对只取一个，并按干净点的最近邻票数决定胜者后，特权收益为 +1.85，相当于自由选择构造的约 32%。约束排除了自由 oracle 的原有选择，真值投票构造的收益也降低了；但 +1.85 不是对所有二选一算法求得的严格最优上界。

曾有成对分类探针得到约 0.694 的 AUC（分类排序指标），但配对方式是“oracle 胜者与其最近败者”，部署时无法构造同一分布。改成部署侧可以生成的自然配对后，按形状交叉验证的 AUC 为 **0.5955**，实际选择收益接近零。较高的诊断 AUC 不能直接作为可部署学习成功的证据。

### 2.5 密度校准和扩散桥

我们也检查了更大尺度的点集分布。使用真实曲面作投影和分区参照时，256、1024 个分区上的基础预测与干净点计数相关性分别约 **0.6446、0.4854**，但计数残差方差比约为 **1.81、1.88**，高于干净点集的约 **1.08**。这说明在该诊断条件下，部分中尺度密度信号仍保留，幅度却有偏差。它没有证明不读取真实曲面时同样能够提取或修正，见 `density_modes`。

跨点云密度差又被用于定位覆盖不足区域。已测主带宽下，即便参照改成真实网格表面测度，取评分最高的 20% 区域时召回率也只有 **0.2034**，接近随机参照 **0.2001**。表面上的平均质量与某一份有限干净点集的具体空缺不是同一对象；已测密度场没有解决后者，见 `mass_field`。

此外，我们在 Jittor 中完成了确定性扩散桥的训练和完整点云评测。当前配置训练 250k、350k、450k 步，dev100 分别为 **57.50、62.14、64.46**，比较基线为 **86.54**，三个节点均为 0/100 形状正向。该集合对桥模型是训练留出集，对比较基线却是训练内样本，因此不是对称泛化对照。结果支持本次配置尚不适合替换现有方案，没有确定扩散桥的充分训练上限，见 `bridge`。

### 2.6 B 榜重叠局部块：有分类信号，仍未选出高分集合

B 榜第二遍网络的重叠局部块在每个开发形状上产生 **600064 个候选**。固定该池，dev20 基线 Final 为 **79.3768**；逐输入点选择其配对真值最近候选为 **+0.2997**，真值支持度全局选择 50000 点则为 **+11.1131**，20/20 正向。它证明现有网络输出包含可构造的高分集合，没有要求先生成新坐标。

随后在 20 个训练形状上拟合 22 维可见特征分类器，在不相交的 20 个验证形状上测得平均 AUC **0.6700**。直接按分数全局选前 50000 点，却下降 **10.8056 Final**；真值到预测距离均值为基线的 **2.171 倍**，p99 均值为 **3.828 倍**。这把瓶颈进一步定位到当前独立分类与无覆盖约束的解码组合：有高于随机的单点排序能力，仍不足以保证集合覆盖。

这组分类 AUC 的目标、数据与候选池均不同于 A 榜自然配对的 0.5955，不能直接作模型排名，但进一步说明旧数值不是通用信息上限。容量诊断与选择器验证沿用同一 dev20，不能把两次结果当作独立复现；逐点真值距离和全局支持度选择的目标不同，也没有求出各自的严格最优值。完整对照见 [研究范围与经验](research_findings.md)，数值见研究指标摘录的 `overlap_capacity`、`overlap_selector`、`overlap_selector_rows`。

## 3. 我们如何理解这个差距

### 3.1 细粒度对应关系是最明显的信息障碍

CD 比较的是两份有限点集。即使曲面估计正确，目标点在曲面上的具体采样位置不同，也会改变最近邻归属和覆盖误差。Oracle 知道这些位置，可以直接安排匹配、位移和选择；实际模型必须从有噪观测中推断。

噪声审计在 100 个训练形状和 80 个本地样本上，测得三维噪声均方根分别约为干净点平均最近邻间距的 **6.48、6.15 倍**。相邻点的对应关系因而有很强的歧义。这与自然配对分类弱、匹配目标难以迁移的结果一致，支持把细粒度归属视为重要障碍，见 `noise_units`。

但 AUC 约 0.595 是已测特征与分类器的结果，不是互信息测量，也不是所有方法共同的理论上限。我们没有估计不可约误差，不能声称“噪声已销毁全部信息”。

### 3.2 表示和输出约束也损失了可用收益

局部均值、分位数和固定向量基压缩了邻域结构；平滑位移场限制了高频修正；逐点独立打分难以描述候选之间的竞争；每对二选一又排除了部分高分点集。对应实验分别出现拟合相关性低、移动不足或特权收益下降。

我们的判断是，失败包含“观测中信号弱”和“当前表示未能利用信号”两部分，还包括预测之后的集合解码损失。B 榜 AUC 为 0.670 而全局选择严重损害覆盖，是后者的直接实例。已有实验无法给出各部分各占多少的可靠比例。密度诊断保留的信号也提醒我们，不同尺度、不同目标的可预测性不能用同一堵“信息墙”概括。

### 3.3 学到一部分方向，不等于得到更高完整点云分数

多步更新会积累方向和曲面误差；小规模固定目标续训可能降低训练损失，却损害验证结果。局部平滑改善某一项几何量，也可能同时损害覆盖或 P2S。形状相关性为正、单步增量为正，都没有自动转化为最终评分。

评分还包含逐形状归一化。未加权原始距离的平均改善，不必然等于归一化分数的平均改善。因此，我们以完整点云 CD、P2S 和 Final 的配套结果决定是否采用，训练损失、方向余弦和密度统计用于解释结果。

### 3.4 有些负结论需要收窄

噪声尺度曾由 `X-Q` 估计。后续逐行真值审计发现，模型残差与原噪声的轴向相关性约 **0.84**，而 `|X-Q|` 中位数仅约为真实噪声幅度的 **0.40**。以它选取的带宽低估了噪声范围；已测阶梯没有覆盖真实三维噪声均方根的尺度，不能写成“完整噪声尺度都已验证失败”。Laplace（拉普拉斯分布）的尺度参数、单轴标准差和三维均方根也不能混作同一个量。

真实表面测度在已测带宽上的洞定位失败，同样不能推广为任意带宽、任意密度表示都不可能成功。高 AUC 配对依赖真值、扩散桥对照不对称、部分训练预算有限，也都限制了结论。

## 4. 对最终方案选择的影响

我们没有达到 oracle。现有证据更支持这样的解释：oracle 的高分依赖真实曲面和有限目标点集的细粒度位置，而已测部署特征与模型对这些信息的恢复不足；输出约束、训练目标及多步误差又进一步损失了收益。这是对当前实验的归纳，尚不是不可突破的理论“信息墙”。

基础模型与第二遍专训仍被保留，是因为它们在实际推理条件下取得了可验证的改善。专训直接学习第一遍输出上的残余误差，没有要求显式重建某一份 oracle 匹配。其收益说明至少一部分残余误差可被继续学习，但不能据此声称已经解决细粒度覆盖问题。A/B 榜最终配置与各自对照见 [实验结果与方案选择](overview.md)。

这些负结果的作用是限定已测方案的适用范围：单纯增加匹配精度、换一种局部平滑、重复更多步或更换轻量选择器，在已有对照下没有得到足够收益。后续方法若要解释 oracle 差距，需要分别验证推理输入中可利用的信号、输出表示能容纳的收益，以及完整点云上的实际改善。
